IMAGES FOLDER - NAMING GUIDE
=============================
Drop STAAD.Pro screenshots here with exactly these filenames.
Supported extensions: .png, .jpg, .jpeg

LOAD DIAGRAMS (Appendix B):
  load_platform_live.png    -> Platform live load diagram
  load_handrail_x.png       -> Handrail load X-axis diagram, when applicable
  load_handrail_z.png       -> Handrail load Z-axis diagram, when applicable
  load_wind_x.png           -> Wind load X-axis diagram
  load_wind_z.png           -> Wind load Z-axis diagram

WIND CALCULATION:
  No extra image is required. Wind is computed from the .std file.

ANALYSIS RESULTS (Appendix C):
  uc_diagram.png                   -> Utilization ratio colour plot
  deflection_vertical.png          -> Vertical deflection contour / diagram
  deflection_horizontal.png        -> Horizontal deflection contour / diagram

CONNECTION STABILITY CHECK (Appendix D):
  connection_table.png      -> STAAD member force / code check table screenshot
                              used to confirm the maximum axial force.

DEFLECTION CHECK (Appendix D):
  deflection_horizontal_table.png  -> STAAD GUI table showing maximum horizontal displacement
                                      for the SLS combination recorded in project_info.txt

Missing images show as labelled placeholder boxes in the report.
